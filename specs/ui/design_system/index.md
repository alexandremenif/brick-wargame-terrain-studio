# Design System Index

This directory defines the atomic UI primitives and visual tokens used across the **Brick Wargame Terrain Studio** web application.

---

## Component Index

* **[`button.md`](./button.md)**: Standard `<Button>` primitive supporting variants (`secondary`, `primary`, `destructive`, `ghost`), sizes (`xs`, `sm`, `icon-xs`), active selection rings, and accessibility focus tokens.
* **[`input.md`](./input.md)**: `<Input>` and `<NumberInput>` single-line controls, dark styling, invalid/rejection feedback, and commit-on-blur mechanics.
* **[`select.md`](./select.md)**: `<Select>` accessible dropdown control for asset switching and mode options.
* **[`modal.md`](./modal.md)**: `<Modal>` accessible dialog with dimming backdrop, focus trapping, Escape dismiss, and action layout.
* **[`badge.md`](./badge.md)**: `<Badge>` metadata and metric tag (`neutral`, `accent`, `subtle`) for dimensions and coordinates.
* **[`tooltip.md`](./tooltip.md)**: `<Tooltip>` hover and focus contextual helper for swatches and tool shortcuts.
